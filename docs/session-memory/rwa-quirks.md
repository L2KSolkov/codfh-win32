RenderWare Audio has no source or symbols, but the user supplied Criterion's PS2 `rwacore.h` (2001), now docs/reference/rwacore_ps2.h (outside include/ so the audit skips it). It is naming evidence: its "Automatically derived from" lines give source file names (rwawave.c, rwaobjdef.c, rwavirtualvoiceobj.c, ...), and its prototypes and structs give function and type names. Xbox layouts mostly follow it (RwaWaveDict, RwaLLNode {prev,next,data}, RwaUniqueID 12 bytes), but its RwReal is an int off-R5900, so it is never compiled. Units are named after those files (src/rwa/rwavirtualvoiceobj.c, rwawave.c). It is decompiled from the asm into src/rwa/ (unit_XXXXXX.c, shared types in src/rwa/rwa.h). Learned 2026-09-30 on unit_23B750.c (36/36 matched):

- **Compiler:** VC7.0 13.00.9466 (C:\XDK\xbox\bin\vc70, from the user's June 2002 XDK 4627), selected by the `/compiler:vc70` pseudo-flag in config/flags.txt; RtFS (src/rw/tool/fsyst) uses it too. Flags `/O2 /Ob1 /G6 /Gy` (RtFS keeps RW's /Ob2), no `/arch:SSE` (x87 only). VC7.0 pads with nop inside each function, ncmp strips trailing nops, and splits run to the next function (no --trim).
- **Missed functions:** parameter handlers are reached only through tables. For example, 0x42E1C8 holds 24-byte entries {param UUID*, 0, 0, type UUID*, 1, handler}; the UUIDs are binary, so they give no names. Add the handlers with `tools/addfn.py ADDR...`, which cuts splits.txt and adds a symbols.txt row; the IDA DB is never edited.
- **Handler shape:** `obj *h(obj *o, const RwaUUID *param, T *value)` returning `o`. A function reading `[esp+0xc]` has the 3-param shape even when the middle parameter is unused.
- **fld/fstp float copy:** where the image copies a float with `fld`/`fstp`, the field is `volatile RwReal`. VC7.1 copies a plain float with integer `mov`, under every flag tried.
- **Byte test form:** `mov al,[x+0x34]; test al,2` instead of `test byte ptr [..],2` came from testing through the local struct pointer (`sound->flags & 2`), not `emitter->sound.flags & 2`.
- **Module globals are file statics:** when the image loads globals before stores through a pointer parameter, declare those globals `static` in the unit. The compiler then knows the pointer can't alias them; /Oa is wrong (it drops dead stores the image keeps). Static .bss data places fine via the dword_XXXXXX names.
- **Same TU evidence:** a caller keeping a value in edx/ecx across a call means the callee is in its translation unit (VC7.1 tracks a known callee's registers); 0x23B750-0x23C450 is one TU so far (unit_23B750.c).
- **VC7.1 vs image:** `(x >> 7) << 7` folds to `and`; write `x / 128 * 128` to keep shr/shl. The `xor ecx,ecx; mov ch,[esp+3]` top-byte test is rwaint.h's rwaLog2 macro (`rwaObjDefSetStateAlignment(def, rwaPow2(0x28))`). It matches once `sub_242150` is declared to return `RwUInt8`; with an int return, every `add esp,4` lands one instruction late. A callee's return width moves the caller's stack-cleanup scheduling.
- **VC7.1-era drafts** (scratchpad rwa_*_draft.c) must be retried under VC7.0. Many docs/questions.md notes from that time were compiler artifacts.
- **Encoding:** the image can encode `[esp]` stores with an explicit disp8 0 (`89 4C 24 00`, VC7.0); ncmp shows them as equal, so check rawcmp/build before committing. Such functions cannot match with VC7.1.
- **Hex constants that fall in .text range** (memory hints like 0x30808) fail the audit: use rwa.h macros (rwaMEMHINTDUR_EVENT | rwaID_808).
- **Audit:** structs must be defined in a header, not the .c file. cmf's header commit doesn't stage src/rwa, so commit rwa.h and config yourself first, then run cmf without -m.
- **Address-taken globals are not static:** a global whose address is taken anywhere (e.g. `&hSemaphore` passed to a create call) can alias pointer stores. Declare it non-static, or the compiler hoists its load over `out->x = ...` stores the image keeps first. Make a module global static only when nothing takes its address and no other unit reads it (check xrefs first: dword_516C60 is read across RW Audio).
- **Dead parameter slots:** VC7.0 puts locals and temporaries in dead parameter home slots. A value returned through `&index` (sub_23F960) or a "default" pointer `p = &unused` (sub_23F300) lands there, as in the image.
- **Tail shapes:** `add esp,4` instead of `pop ecx` after a final call = the function returns the callee's result (`return sub_23DB90(...)`). A release-and-ret in each branch = the success branch releases and the else releases on its own.
- **Struct copies:** `lea esi,[obj+0x28]` with field stores through esi = an embedded struct assigned whole (`stream->open = *params; open = &stream->open;`).
- **Windows calls:** xapilib wrappers (WaitForSingleObject, ReleaseSemaphore, CloseHandle, Sleep) are direct calls: declare them `__stdcall` and add `_Name@N` aliases in config/aliases.txt.
- **Control-flow shapes (VC7.0):** all registers pushed at entry plus one shared `xor eax,eax` epilogue for several failures = `goto fail;` to a single `fail: return NULL;`. An else block laid out before the then block = `x = a ? b : NULL; if (!x) {else} else {then}`. A loop whose only exits are `return TRUE`, with FALSE coming from registers known to be zero = `found = FALSE; ... found = TRUE; break; ... return found;`. Callees fetched as separate statements before a call (`parent = find(); size = f(parent); call(...)`) when the image calls them before loading the other arguments.
- **volatile node fields:** fields the stream thread changes (flags, current index) are `volatile`; the image reloads them between tests.
- **Callback parameters:** a callback that reads its "first" argument from `[esp+8]` has an unused leading parameter (objdef search callbacks take parent, def, data).
- **Store order:** field-by-field struct copies keep the image's (odd) store order in the source; VC7.0 does not reorder independent stores.

- **Register-argument statics (VC7.0 /O2):** the callee picks the registers from its body; parameter order never changes them, but a caller's argument order sets the order it loads them (permute with scratchpad permparams.py/pp.py). Extra stack words the caller pushes = unused trailing parameters (also blocks a tail call: `free(mem, unused)`). An outer call whose inner call result is an argument = a temp statement first (`node = f(); g(node)`). Jump table over a range including no-op values = those cases have their own `result = 0; break;` bodies; `case 6:` first when its block is laid out first.
- **RW string calls:** `call [0x5201F4/FC/0x520200]` = `rwstrcmp`/`rwstricmp`/`rwstrlen` through rwaint.h's `ourGlobals.stringFuncs` struct (never raw offsets: the audit rejects them).
- **Unrotated loops:** `call f; test; je out; call g; jmp top` (no loop inversion, no alignment fill) = `do { x = f(); if (x) g(x); } while (x);` — every `while`/`for(;;)` form gets rotated and aligned.
- **Ring indexes:** fields re-read after a store through another pointer are `volatile` (stream source state's 0x150-0x15C, read requests 0xDC-0xE8); a field read once while both used is not.
- **Loop unrolling:** VC7.0 does unroll ordinary loops. The exact bitmap allocator uses a normal bit++ loop, and the VAG encoder repeats its ordinary sample loop in optimized output. Do not infer hand-written unrolling from repeated instructions alone.
- **VC7.1 Xbox layer (src/rwa/xbox, 2026-10-01):** string literals in `.data` = flags without /GF (/Og /Oi /Ot /Oy /Ob1 /Gs, not /O2). Load/op/store on a flags field (`or [mem]` elsewhere) = `volatile`. A struct copied with alternating ecx/edx movs, not `rep movsd` = field-by-field copy into a different struct. Register-arg static call loading an arg into ecx instead of eax = pass the register argument through a local pointer (`p = &obj->x; f(p, ...)`). A jump table whose cases all fall to one block = cases with dead stores (`config = N;`). A switch returning constants from a local `mode` + `default: mode = 0` when registers swap; `x = 4; if (c) x = 5;` for test/mov/je/mov. `mov eax, ecx` after a call = callee in the same object (ICF-folded copies need an alias). cmf only commits the unit; -m adds include/, docs/, config — NOT src/rwa/*.h: commit those by hand right after (HEAD must build). A statics-only-called-by-a-stripped-function is dropped by the compiler: park it with its caller.

- **Reuse existing scalar locals before trying more expression variants (2026-10-02):** creator 23E690 becomes exact when its final total-size local initially holds the input count, while VAG block 24B510 becomes exact when its old filter local holds the packed header after a separate selectedFilter preserves the index. A fresh local with the same value did not reproduce the allocation. VAG also needs two coefficient pointer locals inside the final loop.
